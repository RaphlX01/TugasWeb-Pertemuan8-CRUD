
# Tugas Rutin 8 — CRUD Inventaris

## Fitur

- List produk (JOIN 3 tabel: inventories + categories + locations)
- Create, Edit, Delete
- Search + Pagination
- Export CSV
- Flash Message (PRG Pattern)
- Delete pakai Transaction + Log
- PDO Singleton + Prepared Statements

## Cara Menjalankan

1. Copy folder `inventaris/` ke `C:\xampp\htdocs\`
2. Start Apache & MySQL di XAMPP
3. Buka `http://localhost/phpmyadmin` → tab SQL → paste `schema.sql` → Go
4. Akses: `http://localhost/inventaris/public/`
